# Stack and Queue

A collection of problems covering stacks, queues, monotonic stacks, and common stack and queue techniques.

## Concepts

### Stack

- Stack Operations
- Parentheses Matching
- Expression Evaluation
- Monotonic Stack
- Next Greater Element
- Next Smaller Element
- Previous Greater / Smaller Element
- Stack Simulation

### Queue

- Queue Operations
- Circular Queue
- BFS
- Deque
- Monotonic Queue
- Queue Simulation
