# Arrays

A collection of array problems covering fundamental techniques such as hashing, prefix sums, array manipulation, sorting, and matrix operations.

## Concepts

- Array Traversal
- Array Manipulation
- Hashing
- Prefix Sum
- Difference Array
- Sorting
- Kadane's Algorithm
- In-Place Manipulation
- Index Mapping
- 2D Arrays / Matrices
